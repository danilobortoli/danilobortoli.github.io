Imagens

  • Colar (⌘V) ou arrastar uma imagem para o texto já a anexa: ela é reduzida a no máximo 1600 px, recomprimida e nomeada assets/images/AAAA/AAAA-MM-DD-titulo.jpg (PNG só se tiver transparência).
  • O botão img abre o seletor de arquivos; img↗ insere uma URL externa. Nos diálogos de figura, deixe a URL vazia para escolher um arquivo.
  • Baixar gera um .zip com o .md e as imagens já nas pastas certas: descompacte na raiz do repositório e comite.
  • Publicar faz o commit direto na main (arquivo + imagens de uma vez) com um token do GitHub guardado só neste navegador.
  • Imagens ficam salvas no navegador junto do rascunho; só as referenciadas no texto vão para o site.

Convenções Tufte

  • Sidenote: footnote kramdown [^1] + [^1]: nota ao final.
  • Newthought: {% raw %}{% include newthought.html text="..." %}{% endraw %}
  • Marginnote: {% raw %}{% include marginnote.html id="mn-1" text="..." %}{% endraw %}
  • Epigraph: {% raw %}{% include epigraph.html quote="..." author="..." %}{% endraw %}
  • Figura: {% raw %}{% include figure.html src="..." alt="..." caption="..." %}{% endraw %}

Convenções do artigo (papel)

  • Seção: ## Da alavanca sai centrada, em versaletes espaçados; ### em itálico.
  • Incipit: <span class="newthought">As primeiras palavras</span>; a capitular vem do campo “Capitular”.
  • Figura de arquivo: {% raw %}{% include figura-artigo.html src="..." alt="..." num="1" caption="..." %}{% endraw %}
  • Figura em SVG: <figure class="art-fig"><svg viewBox="…">…</svg><figcaption>…</figcaption></figure>, usando fill="url(#art-hachura)", url(#art-madeira), <use href="#art-bola">, marker-end="url(#art-seta)" etc. (ver _includes/gravura-defs.html).
  • Prancha: {% raw %}{% include prancha.html src="..." alt="..." num="II" title="..." caption="..." %}{% endraw %}
  • Nota de rodapé: [^1] + [^1]: texto — sai ao pé da folha, não na margem.
  • Equação: $…$ em linha, $$…$$ destacada (MathJax).
  • Ornamento: {% raw %}{% include ornamento-artigo.html %}{% endraw %}
